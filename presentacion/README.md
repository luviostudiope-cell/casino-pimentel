# Presentación · Nuevo sistema del Casino de Pimentel

Material para armar las diapositivas de la propuesta del nuevo sistema.

- `CONTENIDO-DEL-SISTEMA.md`: todo lo que tiene el sistema, cómo se usa y cómo se hizo.
- `marca/`: logo a color y en blanco, emblema del sol, ícono, paleta, QR y guía de colores y tipografías.
- `mockups/`: capturas reales del sistema dentro de laptop, tablet y celular (fondo transparente) y dos escenas sobre fondo azul.

Las pantallas muestran datos de ejemplo (socios, trabajadores y montos ficticios).
